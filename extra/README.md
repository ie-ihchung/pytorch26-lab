각 파일은 **혼자 돌아갑니다.** 앞 교시 코드를 불러오지 않아도 됩니다.

| 파일 | 주제 | 이어지는 곳 | CPU 소요 |

| `02_per_dqn_cartpole.py` | **우선순위 재현 버퍼** — 놀라운 경험을 더 자주 | 2일차 1·4교시 DQN 심화 | 5~8분 |

## 실행

conda activate rl

- **줄마다 주석** — 무엇을 하는 줄인지, 빠뜨리면 어떻게 되는지
- **[해보기]** — 설정값을 바꿔 보며 차이를 확인하는 과제

## 만들면서 실제로 겪은 것

`01_ppo_cartpole.py` 는 처음에 배우와 평론가가 **몸통을 공유**하도록 만들었습니다.
2일차 6교시와 같은 구조였죠. 그런데 점수가 130에서 더 오르지 않았습니다.

원인은 **손실 크기의 불균형**이었습니다.
CartPole 의 목표값은 100 안팎이라 평론가의 제곱 오차가 수천까지 커지는데,
배우 쪽 손실은 0.1 수준입니다. 몸통을 공유하니 평론가 기울기가 배우를 밀어냈습니다.

신경망을 분리하니 **4.3만 스텝에서 495점**으로 해결됐습니다.
이 과정을 코드 주석에 남겨 두었습니다 — 같은 실수를 하기 쉬운 자리입니다.
