# 파이토치 응용 프로젝트

강화학습 3일 과정과 별개로, **파이토치를 넓게 써 보는** 프로젝트 7개입니다.
대표(이애본)가 집필한 파이토치 교재 9~16장을 코랩에서 바로 돌려볼 수 있게 재구성했습니다.

**전부 코랩에서 실행하세요.** 데이터는 자동으로 내려받습니다.

| | 프로젝트 | 난이도 | 시간 | GPU | 교재 |
|---|---|---|---|---|---|
| 01 | DNN 회귀 — 집값 예측 | 입문 | 15분 | | 9장 |
| 02 | CNN — 손글씨 숫자 | 입문 | 20분 | | 10장 |
| 03 | CNN — 옷 종류 | 입문 | 20분 | | 11장 |
| 04 | RNN — 순서 데이터 | 응용 | 20분 | | 12장 |
| 05 | **GAN — 숫자 만들어 내기** | 심화 | 30분 | 권장 | 13장 |
| 06 | **BERT — 한국어 감성 분석** | 심화 | 30분 | 권장 | 15장 |
| 07 | 전이학습 — 사진 분류기 | 응용 | 25분 | 권장 | 16장 응용 |

## 강화학습 과정과 이어지는 곳

- **학습 5단계** — 01·02·03·04·07 전부 같은 다섯 줄
- **detach()** — 05 GAN 에서 판별자를 훈련시킬 때 똑같이 씀
- **남이 학습시킨 모델 가져오기** — 06 BERT, 07 전이학습 (허깅페이스에서 한 그것)
- **손실로 판단하면 안 된다** — 05 GAN 이 정확히 그 경우
