# 실습환경 설치 안내 — PyTorch로 배우는 강화학습

**2026년 7월 27일(월) ~ 29일(수) · 멀티캠퍼스 역삼**

수업 전에 아래대로 설치해 주세요.
설치가 안 되면 수업 당일 실습 시간을 잃게 되니, **전날까지 한 번 실행**해 보시길 권합니다.
끝내 안 되면 Google Colab으로도 3일 전 과정 실습이 가능합니다.

---

## 실습 PC 기준 사양

| 항목 | 사양 |
|---|---|
| CPU | Intel Core i7-8700 |
| GPU | NVIDIA GeForce RTX 2070 |
| OS | Windows |

**GPU는 필수가 아닙니다.** 3일 과정의 모든 실습은 CPU로도 충분히 돌아갑니다.
다만 실습 PC에 RTX 2070이 있으니, 2·3일차 DQN·SAC 학습이 눈에 띄게 빨라지도록 GPU 빌드로 설치하겠습니다.

---

## 1단계 · 아나콘다 설치

아직 없다면 먼저 설치합니다. → https://www.anaconda.com/download

설치 중 **"Add Anaconda to my PATH environment variable"** 항목을 체크하면 편합니다.

---

## 2단계 · 과정 전용 가상환경 만들기

**Anaconda Prompt**를 열고 (윈도우 시작 메뉴에서 "Anaconda Prompt" 검색) 아래를 그대로 붙여넣습니다.

```
conda create -n rl python=3.10 -y
conda activate rl
```

다른 프로젝트와 패키지 버전이 섞이지 않도록 과정 전용 환경을 따로 만드는 것입니다.
앞으로 실습할 때는 **항상 `conda activate rl` 을 먼저** 실행하세요.

---

## 3단계 · PyTorch 설치 (GPU 빌드)

```
pip install torch --index-url https://download.pytorch.org/whl/cu126
```

**이 줄에서 `--index-url` 을 빼면 안 됩니다.**
그냥 `pip install torch` 로 설치하면 Windows에서는 **CPU 전용 버전**이 깔려서, RTX 2070이 있어도 GPU를 전혀 못 씁니다.
용량이 크니 (수 GB) 시간이 좀 걸립니다.

> GPU가 없는 노트북으로 참여하신다면 이 줄만 `pip install torch` 로 바꾸세요. 나머지는 동일합니다.

---

## 4단계 · 강화학습 라이브러리 설치

```
pip install "gymnasium[box2d]" numpy matplotlib
```

`gymnasium`은 실습에 쓰는 강화학습 환경 모음입니다.
`[box2d]`를 붙이는 이유는 미니 프로젝트에서 다루는 **달 착륙선(LunarLander)** 환경이 Box2D 물리엔진을 쓰기 때문입니다. 빼고 설치하면 그 실습만 안 돌아갑니다.

---

## 5단계 · 설치 확인 (중요)

첨부한 `env_check.py` 를 내려받아 아래처럼 실행합니다.

```
python env_check.py
```

**모든 항목이 `[OK]` 로 나오면 준비 완료**입니다.

정상 출력 예시:

```
[OK]   PyTorch: 2.13.0
[OK]   Gymnasium: 1.3.0
[OK]   NumPy: 2.x
[OK]   Matplotlib: 3.x
[OK]   NumPy↔PyTorch 연동: torch.from_numpy 정상 (합 6)
[OK]   GPU(CUDA): 사용 가능 — NVIDIA GeForce RTX 2070 (CUDA 12.6)
[OK]   실습 환경(Gym): 7종 전부 정상
```

`GPU(CUDA)` 항목에 **"사용 가능 — NVIDIA GeForce RTX 2070"** 이 보이면 GPU까지 제대로 잡힌 것입니다.
`사용 불가` 로 나오면 3단계에서 `--index-url` 을 빼고 설치했을 가능성이 큽니다. 아래처럼 지우고 다시 설치하세요.

```
pip uninstall torch -y
pip install torch --index-url https://download.pytorch.org/whl/cu126
```

## 자주 나오는 오류

**`RuntimeError: Numpy is not available`**
PyTorch 빌드와 NumPy 버전이 어긋난 경우입니다. 아래로 맞춰 주세요.
```
pip install "numpy<2"
```

**`ModuleNotFoundError: No module named 'Box2D'`**
4단계에서 `[box2d]` 없이 설치한 경우입니다.
```
pip install "gymnasium[box2d]"
```

**`DeprecatedEnv: Environment version ... is deprecated`**
gymnasium 버전에 따라 환경 이름이 바뀐 경우입니다. 수업 자료는 최신 기준(`CliffWalking-v1`, `Taxi-v4`, `LunarLander-v3`)으로 맞춰 두었으니, 이 오류가 보이면 알려주세요.

**`conda` 명령을 못 찾습니다**
일반 명령 프롬프트가 아니라 **Anaconda Prompt** 에서 실행해야 합니다.
